# EasyYap releases

Installers for EasyYap (called Yappertron until 0.3.0), a push-to-talk dictation app that runs speech-to-text on your own PC. Hold a hotkey, speak, and the text is pasted where you're typing.

This repo holds only the installers. EasyYap checks it for new versions and updates itself.

**To install:** open [Releases](../../releases/latest), download `EasyYap-Setup-<version>.exe` and run it. Windows may warn that the installer isn't signed; choose "More info", then "Run anyway".
