# Yappertron releases

Installers for Yappertron, a push-to-talk dictation app that runs speech-to-text on your own PC. Hold a hotkey, speak, and the text is pasted where you're typing.

This repo holds only the installers. Yappertron checks it for new versions and updates itself.

**To install:** open [Releases](../../releases/latest), download `Yappertron-Setup-<version>.exe` and run it. Windows may warn that the installer isn't signed; choose "More info", then "Run anyway".
